MAX INFOTECH WEBSITE — GITHUB PAGES PACKAGE
===========================================

Files:
- index.html: main website page
- style.css: responsive design and colors
- script.js: mobile navigation, English/Nepali toggle, WhatsApp request form
- images/max-infotech-logo.jpg: logo image supplied in the conversation

HOW TO UPLOAD TO YOUR EXISTING GITHUB REPOSITORY
1. Download and extract this ZIP file.
2. Open your repository: https://github.com/max-infotech/max-infotech.github.io
3. Before replacing anything, make a backup of the current repository (Code > Download ZIP).
4. Upload index.html, style.css, script.js and the images folder to the repository root.
5. If GitHub asks whether to replace files, check the filenames and confirm.
6. Open repository Settings > Pages and make sure Pages is enabled for the correct branch (usually main, / root).
7. Wait a few minutes, then test https://www.maxinfotech.com.np/ in a private/incognito browser tab.

IMPORTANT:
- Keep your existing custom-domain DNS and GitHub Pages settings unless you know they need to change.
- This is a static website. The contact form opens WhatsApp with a prefilled message; it does not save form submissions to a database or send email directly.
- Project cards are illustrative categories, not verified claims of completed projects. Replace them with real work photos/details when available.
- Product categories are examples; update them to match current stock.
- For best results, use your actual optimized logo PNG with transparent background if you have one. The provided logo image is used as supplied.
- The language switch translates the main site labels and core text. Some product/service names remain in English where commonly used.
- No admin panel, database, login system or online inventory is included in this static version.
